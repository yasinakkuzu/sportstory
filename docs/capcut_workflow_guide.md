# CapCut Desktop Script-to-Video Production Guide

## Phase 1 Standard Operating Procedure (SOP)

### 1. The CapCut "Script to Video" (Smart Generation) Workflow
1. Open **CapCut Desktop**.
2. Click **Script to video** on the homepage.
3. Select **Write your own script**.
4. Set script type to **Custom** / **Commercial Video** or paste directly.
5. In the script box:
   - Paste **ONLY** the designated clean Narration text (do not include timestamp brackets or director notes in the voice box).
6. Click **Smart Generation**:
   - Aspect ratio: `9:16` (Vertical).
   - Voice selection: Select a punchy, dramatic male voice (TR: *Mert*, *Barış*, or clean Turkish documentary voice; EN: *Serious Male* / *Narrator*).
   - CapCut automatically sources matching stock B-roll and generates speech.

---

### 2. Manual Polish in CapCut Timeline (Under 2 Minutes)
1. **B-Roll Alignment**:
   - Replace any irrelevant generic stock clips with the recommended search tags specified in each script file (e.g. search "football contract", "money stadium", "Neymar PSG transfer press conference", "soccer tactical board").
2. **Auto-Captions**:
   - Go to **Text** > **Auto captions** > Create.
   - Choose a bold, high-contrast template (e.g., Yellow/White highlight, pop-up single-word animation).
   - Position: Center or slightly lower-third (ensure safe zone: avoid YouTube UI overlay at bottom and right side).
3. **Sound Design (Crucial for 85%+ Retention)**:
   - CapCut audio library: Add a subtle, tense cinematic bass pulse (e.g. *Dark Suspense*, *Documentary Tension*).
   - Set background music volume to `-18 dB` so the voiceover stays crisp and punchy.
   - Add a subtle "whoosh" or "cash register / boom" SFX at transition points (e.g. when figures like "€1.35 Billion" appear).

---

### 3. Export Settings
- **Resolution**: 1080x1920 (9:16)
- **Frame Rate**: 30 fps or 60 fps
- **Bitrate**: Recommended / Higher
- **Format**: MP4 (H.264)
